AI Quiz Generator: how it works

A coach picks one item (scout report, presentation or play), sets a few options and clicks Generate. Our code gathers and compresses the data, one AI call writes multiple-choice questions in a fixed JSON format, and our code turns them into a Pending quiz. Click any step for details.

What the AI receives

One request, two halves

The fixed half is identical for every quiz of the same sport and source type, so the provider caches it and bills it at a tenth (or less) of the normal input price. Only the small variable half is paid in full.

Cached · Base instructions (rules for good quiz questions)~600 tok
Cached · Sport × source prompt (e.g. Football + Scout Report)~500 tok
Cached · Output JSON schema (structured output)~250 tok
Cached · Diagram legend (what each icon/label means)~150 tok
Variable · Compact source data~600–1,500 tok
Variable · Media metadata (if attached)~100–300 tok
Variable · Options + coach note (≤200 chars)~80 tok
Output · Questions only (no IDs, no settings)~90 tok / question

What the AI returns

Output schema

AI output (enforced by schema)

{
  "questions": [
    {
      "q": "Which receiver leads the Hawks
            in receptions this season?",
      "choices": ["#9 Pruitt", "#3 Harlow",
                  "#1 Okafor", "#5 Vance"],
      "correct": 0,
      "focus": "personnel"
    }
  ]
}

Always 4 choices, 1 correct. Exactly N questions, where N comes from the form.

Our code turns it into a quiz

  • IDs & ownership: Random.id(), teamId, createdBy.
  • Type assignment: Classic by default; Recall only if media is attached; Free form keeps choices[correct] as the accepted answer; Stopwatch gets timer defaults.
  • Shuffle choice order so the right answer isn't always first.
  • Media: the selected diagram/photo is attached to every question.
  • Status: saved as Pending; coach reviews, edits and sets Active.

Decisions for the team

Open questions

Model choice

  • Start on Claude Sonnet 5.5 for question quality and sports terminology.
  • Run the same 20 reports through Haiku 5.5; if coaches can't tell the difference, switch (~20× cheaper).
  • A second "summarizer" model is only needed later for long free-text sources (PDFs, long notes).

Usage limits & billing

  • Free generations per team per month, then paid or plan-based.
  • Log tokens and cost per generation, per team.
  • Hard cap per team per day to stop abuse.

Later scope

  • More sources: team stats, playbook, game film, notes.
  • Several items per quiz (e.g. two scout reports).
  • Video questions; mixed media per question; explanations.

Data & privacy

  • No internal IDs, emails or contacts leave our server.
  • Opponent player names and numbers are sent (needed for questions).
  • Confirm the provider's no-training / retention terms.
