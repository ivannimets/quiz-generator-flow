# AI Quiz Generator – flow

Interactive one-page overview of the proposed Just Play AI quiz generator:
pipeline steps, data compaction, AI request, output schema and a cost calculator.

Static site: a single `index.html`, no build step, no dependencies
(fonts load from Google Fonts).

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a repository and push this folder.
2. Repository **Settings → Pages**.
3. **Source:** Deploy from a branch → `main` → `/ (root)` → Save.
4. After ~1 minute the site is at `https://<username>.github.io/<repo>/`.

## Notes

- Token counts and costs are planning estimates (list prices checked Oct 28, 2026).
- Player and team names in the examples are invented.
